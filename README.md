# Velora Fitness

A fictional premium gym website built as a front-end portfolio project with **HTML5, CSS3 and vanilla JavaScript** (no frameworks).

> Velora Fitness is not a real business. All names, prices (₦), contact details, statistics and testimonials are fictional demo content. The registration form is a front-end demo: it validates input but sends nothing and creates no membership.

## Features
- Responsive layout with a working mobile menu and smooth scrolling
- Hero, About, six programme cards, three trainer profiles, three membership plans (Pro highlighted)
- Weekly class timetable with day filters
- Image gallery with keyboard-accessible lightbox (Esc, arrow keys)
- Registration form with inline validation and a clear demo success message
- Plan and programme buttons pre-fill the form
- Branded fallback when an image fails to load; reduced-motion support

## Structure
```
velora-fitness/
├── index.html
├── css/style.css
├── js/script.js
├── assets/images/   (optional local images)
└── README.md
```

## Run it
Open `index.html` in a browser. Fonts and photos load from Google Fonts and Unsplash, so an internet connection is needed.

## Using local images
Download photos into `assets/images/` and change the `IMG()` helper in `js/script.js` to return local paths.
